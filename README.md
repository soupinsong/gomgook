# 📎 딸깍 사전

> ### 논문을 거꾸로 하면 곰국 🍲

논문(생물학·정보학·유전체학)을 읽을 때 **항상 화면 위에 떠서** 번역과 전문용어를
고등학교 1학년 눈높이로 풀어주는 데스크톱 도구.

단어·문장을 **드래그해서 복사(Ctrl+C)** 하면 자동으로 감지해서 풀이해 줍니다.

## 기능

- **항상 위 고정** — 삼성 노트 등 다른 프로그램을 클릭해도 뒤로 숨지 않음 (📌 버튼으로 켜고 끄기)
- **클립보드 자동 감지** — 복사만 하면 바로 풀이 시작
- **문맥 파악** — 같은 단어라도 이 분야에서 어떻게 쓰이는지 설명 (예: `expression` = 발현)
- **문장 속 단어 풀이** — 문장을 본 뒤 그 안의 단어를 다시 복사하면 "이 문맥에서의 뜻"만 콕 집어 설명
- **추가 질문** — 풀이 결과에 대해 "더 쉽게", "예시 하나 더" 처럼 이어서 대화 가능
- **예시 이미지** — 용어의 위키백과 썸네일을 자동으로 띄움
- **쉬운 설명** — 비유를 곁들여 고1 수준으로
- **스트리밍** — 답이 실시간으로 흘러나와서 기다림이 짧음

## 실행 방법

```bash
npm install     # 처음 한 번만
npm start
```

## API 키 설정

기본 엔진은 **무료 Gemini**입니다. 설정에서 언제든 유료 Claude로 바꿀 수 있어요.

### 🆓 Gemini (기본 · 무료)

1. https://aistudio.google.com/apikey 접속 → 구글 로그인 → **Create API key**
   (신용카드 등록 불필요, 넉넉한 무료 할당량)
2. 앱 우측 상단 **⚙ 설정** → Gemini API 키(`AIza...`) 입력 → 저장

환경변수로도 가능: `$env:GEMINI_API_KEY = "AIza..."`

### 💳 Claude (선택 · 유료, 더 안정적)

설정에서 엔진을 **Claude**로 바꾸고 Anthropic 키(`sk-ant-...`)를 넣으면 됩니다.
(https://console.anthropic.com · 환경변수 `ANTHROPIC_API_KEY`)

키는 이 PC(`%APPDATA%/딸깍사전/config.json`)에만 저장되며 외부로 전송되지 않습니다.

## 배포용 실행파일 만들기 (선택)

```bash
npm run dist
```

`dist/` 에 단일 실행파일(portable .exe)이 생성됩니다.

## 구조

```
main.js        Electron 메인 — 창·클립보드 감시·Claude 호출(스트리밍)
preload.js     contextBridge 로 안전하게 API 노출
renderer/      UI (index.html, style.css, renderer.js)
```
